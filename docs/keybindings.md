# 단축키

macOS 기준. 대부분 Cmd 조합이며, Cmd 조합은 앱 단축키로 예약되어 셸로
전달되지 않는다.

## 탭 · 페인

| 키 | 동작 |
|---|---|
| Cmd+T | 새 탭 |
| Cmd+W | 탭(세션) 닫기 — 셸도 종료 |
| Cmd+1 … Cmd+9 | 해당 번호 탭으로 이동 |
| Cmd+Shift+[ | 이전 탭 |
| Cmd+Shift+] | 다음 탭 |
| Cmd+D | 좌우(세로 구분선) 분할 |
| Cmd+Shift+D | 상하(가로 구분선) 분할 |
| Cmd+Option+← / → / ↑ / ↓ | 방향으로 페인 포커스 이동 |
| (페인 클릭) | 그 페인으로 포커스 |

## 블록 · 스크롤

| 키 | 동작 |
|---|---|
| Cmd+↑ | 이전 프롬프트로 점프 |
| Cmd+↓ | 다음 프롬프트로 점프 (맨 아래로) |
| Cmd+클릭 | 하이퍼링크 열기, 없으면 블록 전체 선택 |
| (마우스 휠) | 커서가 올라간 페인 스크롤 (대체 스크린에서는 화살표로 변환) |

## 검색

| 키 | 동작 |
|---|---|
| Cmd+F | 스크롤백 검색 열기 (이미 열려 있으면 다음 매치) |
| Enter | 다음 매치 |
| Shift+Enter | 이전 매치 |
| Esc | 닫기 (스크롤 위치는 유지) |

쿼리는 정규식이며, 대문자가 없으면 대소문자를 구분하지 않는다(smart case).
검색 바가 열려 있어도 Cmd+C 등 Cmd 단축키는 그대로 동작한다.

## 마우스 (TUI 앱)

vim·htop·lazygit처럼 마우스를 켜는 앱에는 클릭·드래그·휠이 그대로 전달된다.

| 키 | 동작 |
|---|---|
| (클릭 · 드래그 · 휠) | 앱으로 전달 |
| Shift+드래그 | 앱에 보내지 않고 **로컬 텍스트 선택** |

Shift는 표준 탈출구다 — htop처럼 화면 전체를 쓰는 앱에서 텍스트를 복사할
유일한 방법이므로 기억해 둘 만하다.

## 복사 · 붙여넣기

| 키 | 동작 |
|---|---|
| Cmd+C | 선택 영역 복사 |
| Cmd+V | 붙여넣기 (bracketed paste 지원) |
| Cmd+Shift+C | 마지막 명령 출력 복사 |
| (드래그) | 선택 · 더블클릭=단어 · 트리플클릭=줄 |

## AI · 팔레트 · Quake

| 키 | 동작 |
|---|---|
| Cmd+K | AI 명령 생성 바 열기 |
| Cmd+Shift+P | 커맨드 팔레트 |
| Ctrl+` | Quake 드롭다운 토글 (전역 — 어느 앱에서든) |

### 오버레이 안에서

| 키 | 동작 |
|---|---|
| Enter | 실행 (AI 생성 / 팔레트 선택 / 다음 매치) |
| Esc | 닫기 |
| ↑ / ↓ | 팔레트 항목 이동 |
| Backspace | 한 글자 지우기 |

## 셸로 전달되는 특수 키

Cmd 조합이 아닌 키는 셸/TUI로 전달된다: 화살표, Home/End, PageUp/Down,
Delete, Tab, Enter, Backspace, Esc, 그리고 Ctrl+A~Z(C0 제어 문자),
Ctrl+Space(NUL).
