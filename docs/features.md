# 기능 가이드

각 기능이 무엇이고 어떻게 쓰는지. 단축키 전체는
[keybindings.md](keybindings.md) 참고.

## 블록 UI (OSC 133 셸 통합)

명령과 그 출력을 하나의 "블록"으로 인식한다.

- 각 명령 블록 왼쪽에 **상태 바**가 뜬다: 실행 중=파랑, 성공=초록, 실패=빨강.
- **Cmd+↑ / Cmd+↓** — 이전/다음 프롬프트로 점프.
- **Cmd+클릭** — 클릭한 블록 전체(프롬프트+명령+출력)를 선택.
- **Cmd+Shift+C** — 마지막으로 완료된 명령의 출력만 클립보드로 복사.

### 셸별 설정

**zsh — 자동.** 설정할 게 없다. 터미널이 `ZDOTDIR`를 잠깐 우회시켜 통합
스크립트를 먼저 읽게 하고, 곧바로 원래 `ZDOTDIR`를 복원하므로 사용자 설정은
그대로 이어진다.

**bash — 한 줄 추가.** bash에는 `ZDOTDIR` 같은 안전한 주입 지점이 없다.
로그인 셸은 `--rcfile`을 무시하고, `--rcfile`을 쓰려고 로그인 셸을 포기하면
`/etc/profile`(path_helper)을 건너뛰어 **PATH가 조용히 달라진다.** 사용자
환경을 몰래 바꾸느니 한 줄을 부탁하는 편이 낫다고 판단했다:

```sh
echo '[ -f ~/.cache/eden/shell/integration.bash ] &&   . ~/.cache/eden/shell/integration.bash' >> ~/.bash_profile
```

스크립트는 터미널을 한 번 실행하면 저 경로에 자동으로 깔린다. macOS 기본
bash 3.2에서도 동작한다.

**fish — 자동. 설정도, 스크립트도 없다.** fish는 3.4부터 OSC 133을 자체적으로
내보낸다. 우리가 할 일이 없다.

fish는 마크에 파라미터를 붙여 보내지만(`A;click_events=1`,
`C;cmdline_url=ls`) 파서가 첫 글자로만 분기하므로 그대로 동작한다.
`src/session.rs`의 테스트가 세 셸의 실제 형식을 모두 고정하고 있다.

셸 통합이 없어도 터미널의 나머지 기능은 전부 동작한다 — 블록 UI와 프롬프트
점프, 상태바의 작업 디렉터리 표시만 비활성화된다.

## 검색 (Cmd+F)

스크롤백 전체에서 문자열을 찾는다.

1. **Cmd+F** → 하단에 `Find>` 바가 열린다.
2. 입력하는 즉시 검색된다. 모든 매치가 노랑으로 칠해지고, 현재 매치는 더 진하게.
3. 오른쪽에 `3/17`처럼 위치와 총 개수가 뜬다.
4. **Enter** 다음 매치 / **Shift+Enter** 이전 매치 — 히트가 화면 가운데로 온다.
   이미 화면에 보이는 매치면 스크롤하지 않는다.
5. **Esc** — 닫는다. 스크롤 위치는 그대로 둔다 (브라우저의 Cmd+F와 같다).

쿼리는 **정규식**이다. 대문자를 쓰지 않으면 대소문자를 구분하지 않는다(smart case) —
`error`는 `Error`도 찾지만 `Error`는 정확히 그것만 찾는다. 입력 도중 `(`처럼 정규식이
아직 완성되지 않으면 바에 `invalid`가 뜬다 (크래시하지 않는다).

검색 중 셸에서 명령을 실행해 새 출력이 쌓여도 기존 하이라이트는 올바른 줄에 남는다.
한글 입력도 바에서 조합된다. 검색 바가 열려 있어도 Cmd+C 복사는 그대로 동작한다.

제한 — 매치는 1000개까지만 모은다(`.` 같은 쿼리 방어). 포커스를 다른 페인으로
옮기면 검색이 닫힌다.

## 마우스 (TUI 앱 지원)

vim·htop·lazygit·btop처럼 마우스를 요구하는 앱에 클릭·드래그·휠이 그대로 전달된다.
앱이 켜는 모드(1000/1002/1003)와 인코딩(SGR·UTF-8·레거시)을 따라간다.

- vim에서 `:set mouse=a` 후 클릭하면 커서가 가고, 드래그하면 비주얼 선택이 된다.
- htop에서 컬럼 헤더를 클릭해 정렬한다.
- **Shift+드래그는 앱에 보내지 않고 로컬 텍스트 선택**을 한다. htop처럼 화면 전체를
  쓰는 앱에서 텍스트를 복사할 유일한 방법이므로 알아둘 만하다 (xterm·iTerm2 공통 관례).
- Cmd+클릭은 종전대로 하이퍼링크/블록 선택이다.

## AI 명령 생성 (Cmd+K)

자연어(한/영)로 원하는 걸 말하면 셸 명령을 만들어 준다.

1. **Cmd+K** → 하단에 `AI>` 입력 바가 열린다.
2. 예: "최근 24시간 안에 수정된 파일 찾아줘" 입력 후 **Enter**.
3. 생성된 명령이 프롬프트에 **삽입만** 된다 (자동 실행 안 함). 확인 후 Enter로 실행.
4. **Esc** — 취소.

**모델 라우팅 (로컬 우선, 계정 강제 없음)**:

1. `ANTHROPIC_API_KEY` 환경변수가 있으면 Anthropic API 사용 (BYOK).
2. 없으면 로컬 [Ollama](https://ollama.com) 사용
   (`EDEN_OLLAMA_URL`, 기본 `http://localhost:11434`;
   `EDEN_OLLAMA_MODEL`, 기본 `llama3.2`).

포커스된 페인의 최근 화면과 마지막 명령의 종료 코드를 컨텍스트로 함께 보내므로
"방금 그 에러 고쳐줘" 같은 요청도 맥락을 반영한다.

## 탭과 분할 (내장 멀티플렉서)

tmux 없이 탭과 페인 분할을 쓴다.

- **Cmd+T** 새 탭 / **Cmd+W** 탭(세션) 닫기 / **Cmd+1..9** 탭 이동.
- **Cmd+Shift+[ / ]** 이전/다음 탭.
- **Cmd+D** 좌우 분할 / **Cmd+Shift+D** 상하 분할.
- **Cmd+Option+화살표** 페인 포커스 이동, 또는 페인 클릭.
- **Cmd+Z** 포커스된 페인을 탭 전체로 확대 / 다시 눌러 복원 (tmux의 `prefix+z`).
  분할 구조는 그대로 남아 있어 풀면 정확히 원래대로 돌아온다. 줌 중에는 탭
  제목에 `[Z]`가 붙는다 — 다른 페인이 사라진 것처럼 보이기 때문이다.
  분할·페인 닫기·포커스 이동을 하면 자동으로 풀린다.
- **구분선을 드래그**하면 페인 크기를 바꿀 수 있다. 한쪽이 사라질 만큼은
  끌리지 않는다(10~90%). 중첩 분할에서도 잡은 구분선만 움직인다.
- 마우스 휠은 커서가 올라간 페인을 스크롤한다.
- `inactive-dim` 설정을 켜면 **비활성 페인이 은은하게 어두워져** 포커스된
  페인이 한눈에 보인다 (iTerm2 Dim inactive split panes). 기본은 끔.

## 세션 지속성 (detach / attach)

셸과 실행 중인 프로그램이 창을 닫아도 살아남는다.

- 창을 닫으면 **detach** — 셸은 데몬에 남는다.
- 다시 실행하면 살아있는 세션들이 **탭으로 복원**된다 (화면·스크롤백·실행 상태).
- **분할 구조도 함께 복원된다** — 탭 순서, 페인 트리, 분할 비율, 포커스된
  페인, 활성 탭까지. 구조는 `~/.cache/eden/layout.json`에 저장된다.
- **Cmd+W** 또는 셸에서 `exit` 하면 그 세션이 완전히 종료된다.

복원 중 일부 세션이 사라졌으면(그 셸만 `exit` 했다면) 그 페인만 트리에서
빠지고 남은 페인이 자리를 채운다. 파일이 없거나 깨졌으면 예전처럼 세션당
탭 하나로 폴백한다. 줌 상태는 일시적인 것이라 저장하지 않는다.

동작 원리는 [architecture.md](architecture.md)의 mux 데몬 참고.

## 하이퍼링크 · URL (Cmd+클릭)

**OSC 8 링크** (`ls --hyperlink`, 컴파일러 에러의 파일 경로 등)와 화면에 그냥
찍힌 **평문 URL**이 모두 밑줄로 표시되고 **Cmd+클릭**으로 기본 앱에서 열린다
(macOS `open`).

평문 URL은 스킴이 있어야 인식한다 — `https` `http` `file` `git` `ssh` `ftp`
`mailto`. `www.` 같은 스킴 없는 휴리스틱은 쓰지 않는다(오탐이 많고 `open`에
넘길 수도 없다). 문장 끝의 `.` `,` `)` 같은 문장부호는 자동으로 잘라내되,
`https://a.com/b(c)`처럼 URL 안에서 괄호 짝이 맞으면 보존한다.

같은 자리에 OSC 8 링크와 평문 URL이 겹치면 **OSC 8이 이긴다.** 표시 텍스트와
실제 주소가 다를 수 있는 게 OSC 8의 존재 이유라, 추론이 이기면 엉뚱한 주소가
열린다. 링크가 아닌 곳을 Cmd+클릭하면 블록 선택으로 폴백한다.

## 명령 완료 알림

긴 빌드·테스트가 끝났는데 다른 창을 보고 있었다면 알려준다. OSC 133 셸
통합(위 블록 UI)이 켜져 있어야 동작한다.

- 조건: **`notify-threshold`초(기본 10초) 이상 걸린 명령**이, **보고 있지 않을
  때** 끝났을 때. "보고 있지 않다"는 창이 비포커스이거나, 창은 앞에 있어도 그
  페인의 탭이 비활성인 경우다.
- 전달: Dock 아이콘 바운스 + 알림 배너. 배너는 최초 1회 권한 프롬프트가 뜨고,
  서명된 `.app` 번들에서 앱 이름·아이콘이 제대로 붙는다.
- 본문에는 방금 끝난 명령의 프롬프트 줄이, 제목에는 결과와 소요 시간이 들어간다
  (예: "명령 실패 (exit 2, 1분 12초)").

앱이 직접 보내는 알림 시퀀스도 지원한다. 조건(보고 있지 않을 때만)은 같다.

```
printf '\e]9;빌드 끝났습니다\a'                 # OSC 9 (iTerm2)
printf '\e]777;notify;제목;본문\a'              # OSC 777 (rxvt)
```

`notify = off`로 전부 끌 수 있다. detach 후 재접속할 때 과거 출력이 재생되면서
옛 알림이 다시 울리는 일은 없다.

## 커맨드 팔레트 (Cmd+Shift+P)

자주 쓰는 동작을 검색해서 실행한다.

1. **Cmd+Shift+P** → 화면 중앙에 팔레트가 뜬다.
2. 타이핑으로 부분일치 필터 (예: "split").
3. **↑/↓** 선택, **Enter** 실행, **Esc** 닫기.

제공 액션: 새 탭, 페인 닫기, 좌우/상하 분할, 페인 줌, 다음/이전 탭,
AI 명령 생성, 스크롤백 검색, 이전/다음 프롬프트 점프, 마지막 출력 복사.

팔레트와 키바인딩은 **같은 액션 집합**을 쓴다. 그래서 단축키로 되는 일은
팔레트에서도 되고, 설정에서 재정의한 키도 같은 동작을 부른다.

## Kitty keyboard protocol (CSI u)

Neovim 같은 최신 TUI가 `Shift+Enter`를 `Enter`와, `Ctrl+I`를 `Tab`과 구분해
받을 수 있게 하는 확장 키보드 프로토콜이다. 프로토콜 5개 플래그(키 구분,
이벤트 종류, 대체 키, 전체 키 보고, 연관 텍스트)를 모두 지원한다.

**기본은 꺼져 있다.** 설정에 `kitty-keyboard = on`을 넣어 켠다. 반쪽 인코딩은
앱의 키 입력을 통째로 깨뜨릴 수 있어서, 충분히 검증되기 전까지 탈출구를
남겨 둔 것이다. 프로토콜을 요청하지 않는 앱(zsh·fzf 등)은 켜든 끄든 예전
그대로 동작한다.

## Quake 드롭다운 (Ctrl+`)

**Ctrl+`** 전역 핫키로 어느 앱에서든 터미널을 화면 상단에 즉시 소환하거나
숨긴다. 소환 시 현재 모니터 상단 중앙에 배치되고 포커스된다.

## 한글 IME · 선택 · 클립보드

- 한글 입력 시 조합 중 글자를 커서 위치에 표시하고 후보창을 배치한다.
  검색 바·AI 바가 열려 있으면 조합도 그 바에서 렌더링된다.
- **한글 입력 소스에서도 Cmd 단축키가 동작한다** — 단축키가 물리 키 위치로
  매칭되고, Cmd를 누르는 동안 IME를 잠시 꺼서 macOS가 조합 중 키 이벤트를
  삼키는 문제를 우회한다. 조합 중(밑줄)에 Cmd를 누르면 조합 중이던 글자는
  버려지고 단축키가 실행된다. Claude Code처럼 한글로 오래 입력하는 TUI에서도
  Cmd+T·Cmd+D 등이 그대로 먹힌다.
- 드래그 선택, 더블클릭=단어, 트리플클릭=줄.
- **Cmd+C** 복사 / **Cmd+V** 붙여넣기 (bracketed paste 지원, 비지원 시
  개행을 `\r`로 정규화해 의도치 않은 실행을 줄인다).
- **파일을 창에 드래그 앤 드롭**하면 경로가 셸 인용되어 입력줄에 붙는다
  (Terminal.app·iTerm2 관례). 공백·한글 파일명은 작은따옴표로 감싸지고,
  여러 파일을 드롭하면 공백으로 구분된다.
- 터미널 앱의 OSC 52 클립보드 읽기/쓰기도 처리한다.

## 하단 상태바

창 맨 아래에 상태바가 항상 표시된다 (iTerm2 상태바와 유사).

- **왼쪽**: 현재 작업 디렉터리(홈은 `~`로 축약) + git 브랜치.
- **오른쪽**: CPU 사용률 · 메모리(사용/전체) · 시계(HH:MM:SS).

작업 디렉터리는 셸 통합이 보내는 **OSC 7**로 추적하고, git 브랜치는 그
디렉터리에서 상위로 올라가며 `.git/HEAD`를 읽어 구한다. 시계·CPU·메모리는
1초마다 갱신된다.

## 설정 · 테마 · 프리셋

`~/.config/eden/config`에서 폰트·색·스크롤백을 바꾼다. `theme = guezwhoz`
같은 컬러 프리셋과 16색 ANSI 팔레트, 커서 모양, 배경 투명도를 지원한다.

- **폰트 크기 런타임 조절** — **Cmd+=** 키우기 / **Cmd+-** 줄이기 /
  **Cmd+0** 설정값 복귀. 셀·PTY 크기가 즉시 다시 맞춰진다.
- **라이트/다크 자동 전환** — `theme-light` / `theme-dark`를 두면 macOS
  외양이 바뀌는 순간 재시작 없이 색이 갈아탄다. 라이트 프리셋으로
  `latte`(Catppuccin Latte)가 내장돼 있다.

폰트는 설정 없이도 MesloLGS Nerd Font(설치돼 있으면) → Menlo → Monaco →
SF Mono 순으로 자동 선택되고, 파워라인 글리프·한글·기호는 폴백 체인이
알아서 채운다. 자세한 항목은 [configuration.md](configuration.md), 예시는
[`config.example`](../config.example).

iTerm2를 쓰던 사람은 iTerm2의 프로파일 색을 그대로 옮길 수 있다 —
`Custom Color Presets`의 16색 값을 `palette-0`~`palette-15`로, 배경/전경/커서를
각 키로 넣으면 된다. `guezwhoz` 프리셋은 iTerm2 Guezwhoz 스킴을 내장한 예다.
